# Bot Dream Team™ Skills

One standalone skill for small businesses and real estate teams: accurate after-hours reply drafts and clear morning handoffs.

## Install

```sh
npx skills add botdreamteam/skills
```

Ask your agent: “Use after-hours-lead-responder to prepare replies to these inquiries.”

Works with pasted messages; no paid product or connector required. Drafts only by default. Installing does not connect an inbox, monitor messages, or deploy a chatbot.

See [the skill](skills/after-hours-lead-responder/SKILL.md).
